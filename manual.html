คู่มือการใช้งาน LabPath สพช.69

ระบบบันทึกผลแลป ค่ายสัตวแพทย์อาสา สพช. 2569 · ต.ดงใหญ่ อ.พิมาย · ฉบับ 13 พ.ย. 2569
ต้อง "รับตัวอย่าง" ก่อนเสมอ ระบบจะออกเลขตัวอย่างและสร้างหน้าของสัตว์ตัวนั้น แล้วผลแลปทุกอย่างลงในหน้านั้น — ยังไม่รับตัวอย่าง = ยังลงผลไม่ได้

ลิงก์เข้าใช้งาน (มือถือหรือคอมก็ได้):
https://sorporchor69.github.io/labpath69/

1. ภาพรวมขั้นตอน

① รับตัวอย่าง→② ได้เลขตัวอย่าง→③ ตรวจ F / L→④ ลงผลแลป→⑤ ส่งให้ Lab-path→⑥ ตรวจสอบแล้ว ✓
  1. รับตัวอย่าง ที่หน่วย — กรอกข้อมูลสัตว์สั้น ๆ และติ๊กว่าส่งตรวจอะไร
  2. เขียนเลขตัวอย่าง ที่ได้ (เช่น HN 1-SA-02-003 = Day 1 · สัตว์เล็ก (SA; หน่วยสูติกรรมใช้ OB, โคใช้ LA) · กลุ่ม 02 · ลำดับที่ 003 — ลำดับที่คือลำดับสัตว์ที่เข้าหน่วย กรอกเองตอนรับตัวอย่าง) ลงหลอด/ถุงตัวอย่างทันที
  3. ตรวจ ที่หน้างาน (F Field) หรือในห้องแลปช่วงบ่าย (L Lab)
  4. ลงผล ในหน้า "ผลแลปวันนี้" แท็บของการตรวจนั้น แล้วกดบันทึก
  5. ลงผลครบทุกการตรวจของตัวนั้น → กด "ส่งให้ Lab-path ตรวจสอบ"
  6. Lab-path กด "ตรวจสอบแล้ว" หรือ "ส่งกลับแก้ไข" พร้อมเหตุผล

2. เข้าใช้งาน

  1. เปิดลิงก์ด้านบน → ใส่ รหัสค่าย (PIN) ที่ได้รับในกลุ่มค่าย → กด "ถัดไป"
  2. พิมพ์ ชื่อจริง (ไม่ต้องใส่นามสกุล ไม่ต้องใส่ นาย/นางสาว) เช่น อารัทธ์
  3. ระบบขึ้น 🔒 กลุ่มของคุณ ตามรายชื่อค่ายเอง (เปลี่ยนเองไม่ได้) → กด "เข้าใช้งาน"
  • ชื่อซ้ำ (เช่น ณภัทร, ณิชากร) — ระบบขึ้นปุ่มชื่อ-สกุลให้แตะเลือกตัวเอง
  • พิมพ์แล้วไม่เจอ — ตรวจการสะกด หรือแจ้งฝ่าย Lab-path ให้แก้รายชื่อ
  • ระบบให้ เข้าใหม่ทุกวัน (ยืนยันชื่อทุกเช้า) · ใช้มือถือร่วมกับเพื่อน → เมนู "ออกจากระบบ" ก่อนส่งต่อ
  • แนะนำ "เพิ่มไปยังหน้าจอโฮม" (iPhone: Safari › แชร์ › Add to Home Screen · Android: Chrome › ⋮ › Add to Home screen)
  • ห้ามใช้โหมดไม่ระบุตัวตน (Incognito/Private) — ข้อมูลที่รอส่งตอนเน็ตหลุดจะหาย
ชื่อที่ใช้เข้าระบบจะถูกบันทึกเป็น "ผู้บันทึก/ผู้แก้ไข" ในทุกข้อมูลที่คุณเพิ่มหรือแก้ และระบบเก็บประวัติไว้ทุกครั้ง

3. รับตัวอย่าง (ทำก่อนทุกครั้ง)

เมนู ＋ รับตัวอย่าง (ปุ่มชมพูกลางเมนูล่างบนมือถือ)

  1. วันค่าย — ระบบเลือก Day ของวันนี้ให้แล้ว
  2. หน่วยที่เก็บตัวอย่าง — เลือกหน่วยที่ออกวันนี้ ชนิดสัตว์จะเปลี่ยนตามหน่วยเอง:
    หน่วยชนิดสัตว์ที่เลือกได้เลขตัวอย่างที่ได้ (ตัวอย่างของกลุ่ม 12)
    SA อายุรกรรมสัตว์เลี้ยง (Day 1–3)สุนัข · แมว1-SA-12-001
    BC อายุรกรรมโค – โคเนื้อ (Day 1–3)โคเนื้อ · โคนม1-LA-12-001
    DC โคนม สหกรณ์โคนมพิมาย (Day 4–5)โคเนื้อ · โคนม4-LA-12-001
    OB สูติกรรม / ทำหมัน (Day 1–5)สุนัข · แมว1-OB-12-001
  3. ชนิดสัตว์ + ชื่อสัตว์ (สัตว์เล็ก) หรือ Ear tag / ฟาร์ม (โค) + ชื่อเจ้าของ หมู่ที่
  4. ส่งตรวจอะไรบ้าง (ติ๊กได้หลายอย่าง) — Blood (CBC) · Blood parasite · Fecal exam · Cytology · Urinalysis · Test kit · Derm · Ocular · Vaginal cytology
    ตัวอย่างจะไปรอในแท็บของการตรวจที่ติ๊กไว้ในหน้า "ผลแลปวันนี้"
  5. กด 💾 บันทึก + ออกเลขตัวอย่าง → จดเลขลงหลอดทันที
  • ข้อมูลเพิ่มเติม (ไม่บังคับ) — เพศ อายุ สายพันธุ์ ที่อยู่ ประวัติวัคซีน ฯลฯ อยู่ในหัวข้อที่พับไว้ กรอกเฉพาะที่จำเป็น
  • ตัวต่อไปบ้าน/ฟาร์มเดียวกัน → หลังบันทึกกด "🏠 รับตัวอย่างตัวต่อไปในบ้านเดียวกัน" ไม่ต้องกรอกเจ้าของซ้ำ
  • ถ้าเป็นสัตว์ชื่อเดิม + เจ้าของเดิม + วันเดียวกัน ระบบจะถามก่อนว่าซ้ำหรือไม่
  • เน็ตหลุด → บันทึกได้ตามปกติ แต่จะขึ้น "รอเลข" — เขียนชื่อสัตว์บนหลอดไว้ก่อน แล้วเติมเลขเมื่อออนไลน์

4. ลงผลแลป

เมนู 🧪 ผลแลปวันนี้ → เลือก Day → เลือก แท็บการตรวจ (Blood · Blood parasite · Fecal · Cytology · Urine · Test kit · Derm · Ocular · Vaginal)

  1. ในแท็บจะเห็นรายชื่อตัวอย่างที่ส่งตรวจวันนั้น · ตัวเลขบนแท็บ เช่น 3/7 = ลงผลแล้ว 3 จาก 7 ตัว
  2. กด "ลงผล" ที่ตัวที่ต้องการ (กรอง "ยังไม่ลงผล" ช่วยหาง่าย)
  3. เลือก F หรือ L ว่าตรวจที่ไหน แล้วกรอกผล ส่วนใหญ่เป็นปุ่มกดเลือก
  4. กด 💾 บันทึกผล — ทำซ้ำทีละแท็บจนครบทุกการตรวจของตัวนั้น
  5. เปิดแท็บ "สรุปการตรวจ" ของตัวนั้น → ตรวจว่าครบ → กด "ลงผลครบแล้ว — ส่งให้ Lab-path ตรวจสอบ"

ตัวช่วยตอนกรอก

  • ค่าอ้างอิง ขึ้นใต้ช่อง (สุนัข / แมว / โค) · ค่าสูง/ต่ำกว่าอ้างอิงขึ้น ↑ ↓ สีเหลือง — ยังบันทึกได้
  • ค่าที่เป็นไปไม่ได้ บันทึกไม่ได้: Hct 0–80 %, TP 0–15 g/dL, USG 1.000–1.080
  • Differential count ต้องรวมได้ 100% — มีผลรวมขึ้นให้ดูสด ๆ
  • พิมพ์ค้างไว้แล้วออกจากหน้า ระบบจำร่างไว้ให้
  • หน้าสัตว์ แท็บ "สรุปการตรวจ" ยังแสดง "เคยตรวจอะไรบ้าง" ของสัตว์ตัวเดียวกันในวันอื่น (เทียบ ear tag หรือชื่อ + เจ้าของ)
  • หาสัตว์ตัวเดิม: เมนู 🔍 ค้นหาสัตว์ — พิมพ์เลขตัวอย่าง ชื่อสัตว์ เจ้าของ ฟาร์ม หรือ ear tag

5. Blood parasite ในโค (กรอกเป็นชุด)

เมนู 🐄 Blood parasite โค → แท็บ "กรอกเป็นชุด" — ใช้กับการสำรวจความชุก (PBL Bovine Blood Parasite)

  1. กรอกข้อมูลฟาร์มครั้งเดียว: วัน หน่วย ฟาร์ม เจ้าของ หมู่ ชนิดโค วิธีตรวจ
  2. ตารางรายตัว: หมายเลขสัตว์ อายุ (ปี) เพศ สายพันธุ์ แล้ว ติ๊กเชื้อที่ Positive (ไม่ติ๊ก = Negative)
  3. ไม่พอ → "＋ เพิ่ม 5 แถว" · เสร็จแล้วกด 💾 บันทึกทั้งชุด (ระบบออกเลข เช่น 4-LA-12-BP001)
  4. แก้ผลรายตัว: แท็บ "รายการทั้งหมด" → แตะแถว
  5. แท็บ "ความชุก" แสดง % + 95% CI รายเชื้อ แยกฟาร์ม/วัน/เพศ และ export CSV ได้

6. เบิก/คืน Test kit และจองห้องแลป

Test kit (ตู้เย็นแลป)

  1. เมนู เบิก/คืน Test kit → "＋ เบิก test kit" → เลือกหน่วย รายการ จำนวน → บันทึก
  2. กลับจากหน่วยแล้ว นับที่เหลือ → กด "บันทึกยอดคืน" ในกล่องแดง ระบบคำนวณ "ใช้ไป" ให้
  3. รายการที่ยังไม่คืนค้างอยู่ในกล่องแดงจนกว่าจะบันทึกยอดคืน · ตารางคงเหลือในตู้อัปเดตเอง

จองห้องแลป (ช่วงบ่าย 13.30–17.00 น.)

  1. เมนู จองห้องแลป → เลือก Day → กด "＋ จองช่วงนี้" ในช่วงเวลาที่ต้องการ
  2. เลือกหน่วย (กลุ่มเป็นของคุณอัตโนมัติ) ใส่ว่าจะตรวจอะไรถ้าต้องการ → จอง
  3. ช่องละไม่เกิน 5 กลุ่ม · เต็มแล้วจะจองไม่ได้ · ยกเลิกได้เฉพาะคนที่จองเอง

7. สำหรับฝ่าย Lab-path

เข้าด้วย PIN ของ Lab-path (แจกแยก ห้ามส่งในกลุ่มรวม)

  • ตรวจสอบผล: หน้าสัตว์ → "สรุปการตรวจ" → ✓ ตรวจสอบแล้ว หรือ ↩ ส่งกลับแก้ไข + เหตุผล (กลุ่มจะเห็นเหตุผลในหน้านั้น)
  • หน้า 📋 ภาพรวม / สถานะตรวจสอบ แสดงรายการ "รอตรวจสอบ" ทั้งหมด
  • 🖨 พิมพ์ใบรายงานผล (A4): หน้าสัตว์ → "สรุปการตรวจ" → เลือกเครื่องพิมพ์หรือ "บันทึกเป็น PDF" (มีช่องลงชื่อผู้บันทึก/ผู้ตรวจสอบ)
  • 📊 รายงาน / Export: สรุปจำนวนตัวอย่าง · ความชุกพยาธิทางเดินอาหาร · พยาธิในเม็ดเลือด · Test kit % positive · Export CSV ทุกตาราง (มีแบบตัดข้อมูลเจ้าของสำหรับเผยแพร่)
  • ⚙️ ตั้งค่า (Admin เท่านั้น): จำนวน kit ตั้งต้น · เวลาจองห้อง · ตัวเลือกในฟอร์ม · รายชื่อนิสิตและกลุ่ม · ลบข้อมูลทดลอง

8. ใครแก้อะไรได้ · ปัญหาที่พบบ่อย

Lab-pathทุกอย่างของนิสิต + แก้ได้ทุกกลุ่ม · ตรวจสอบ/ส่งกลับแก้ไข · รายงาน/Export

มุมขวาบน ⏳ รอส่ง n รายการเน็ตหลุด ข้อมูลอยู่ในเครื่องแล้ว ระบบส่งเองเมื่อมีเน็ต (ลองใหม่ทุก 30 วินาที) — อย่าล้างข้อมูลเบราว์เซอร์
มุมขวาบน ⚠ มีปัญหาแตะป้าย → ดูว่ารายการไหนส่งไม่ผ่าน → "ลองใหม่" หรือ "ทิ้ง"
หน้าต่าง "ข้อมูลถูกแก้โดยคนอื่น"มีคนแก้ตัวเดียวกันพร้อมกัน → เลือกทีละช่องว่าจะใช้ค่าของเราหรือค่าล่าสุด → บันทึก (ระบบไม่เขียนทับกันเอง)
ปุ่มบันทึกไม่ขึ้น / "ดูได้อย่างเดียว"ตัวอย่างนั้นเป็นของกลุ่มอื่น → ให้กลุ่มนั้นหรือ Lab-path แก้
ข้อมูลจากเพื่อนยังไม่ขึ้นรอ ~30 วินาที หรือแตะป้ายสถานะ → "ซิงก์ตอนนี้"
บันทึกแล้วขึ้น "Differential count รวมต้อง 100%"ตรวจตัวเลข % ของเม็ดเลือดขาวให้รวมได้ 100
